데이터허브코리아 데이터 엔지니어 신입/주니어 채용

회사 소개
데이터허브코리아는 금융권 대상 데이터 분석 플랫폼을 운영하는 시리즈 B 스타트업입니다.

담당 업무
- 데이터 수집·적재 파이프라인 개발 (Airflow, Spark)
- 데이터 웨어하우스 모델링 (BigQuery)
- 데이터 품질 모니터링 대시보드 구축

지원 자격
- 학력: 대졸 이상 (컴퓨터공학, 통계학 등 관련 전공)
- Python 또는 Java 프로그래밍 가능하신 분
- SQL 작성 능력 (조인, 윈도우 함수 수준)
- 신입 또는 경력 2년 이하

이런 분이면 더 좋아요
- ADsP, SQLD 등 데이터 관련 자격증 보유자
- Airflow, dbt 등 데이터 파이프라인 도구 사용 경험
- 영어 문서 독해에 어려움이 없는 분 (토익 800 이상 우대)

근무 환경
- 근무지: 경기 성남시 분당구 판교역로
- 연봉: 회사 내규에 따름 (신입 기준 4,200만원 이상)
- 유연근무제, 재택 주 2회

채용 절차 및 기간
- 상시 채용 (채용 시 마감)
- 서류 → 코딩 테스트 → 실무 면접 → 임원 면접
