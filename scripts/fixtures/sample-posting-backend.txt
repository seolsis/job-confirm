[클라우드웨이브] 백엔드 개발자 (경력 3년 이상)

클라우드웨이브는 이커머스 셀러를 위한 재고·주문 통합 관리 SaaS를 만듭니다.
월 거래액 1,200억 원을 처리하는 커머스 인프라를 함께 키워갈 백엔드 개발자를 찾습니다.

주요 업무
- 주문/재고 동기화 API 서버 개발 및 운영 (Python, FastAPI)
- 오픈마켓 연동 파이프라인 설계 (쿠팡, 스마트스토어, 11번가)
- PostgreSQL 기반 데이터 모델링 및 쿼리 최적화
- 대용량 트래픽 처리를 위한 비동기 워커 구조 개선 (Celery, Redis)

자격 요건
- Python 기반 웹 프레임워크(Django, FastAPI 등) 실무 경험 3년 이상
- RDBMS(PostgreSQL, MySQL 등) 설계 및 운영 경험
- REST API 설계 및 문서화 경험
- Git 기반 협업 및 코드 리뷰 문화에 익숙하신 분

우대 사항
- AWS 환경(ECS, RDS, SQS) 운영 경험
- 대용량 트래픽 또는 커머스 도메인 경험
- Kubernetes 기반 배포 경험
- 정보처리기사 자격증 보유

근무 조건
- 근무지: 서울 강남구 테헤란로 (역삼역 도보 5분)
- 고용 형태: 정규직 (수습 3개월)
- 연봉: 6,000만원 ~ 8,500만원 (경력에 따라 협의)
